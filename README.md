# QR File Share 📲💻

تطبيق نقل الملفات بين الهاتف واللابتوب عبر تقنية **WebRTC** باستخدام **PeerJS** — سريع، آمن، ومباشر بدون سيرفر وسيط.

## ✨ المميزات

- ⚡ نقل ملفات **P2P مباشر** — لا يمر عبر أي سيرفر
- 📱 مسح **QR Code** من الهاتف للاتصال الفوري
- 📊 **شريط تقدم** حي أثناء نقل الملفات
- 💾 **تحميل تلقائي** فور اكتمال الاستقبال
- 🌙 تصميم **داكن أنيق** بتأثيرات Glassmorphism
- 📱💻 واجهة **متجاوبة** — تتكيف مع الهاتف واللابتوب
- 🔐 اتصال **مشفّر** عبر WebRTC

## 🛠️ التقنيات

- **Next.js 16** (App Router)
- **TypeScript**
- **Tailwind CSS 4**
- **PeerJS** — WebRTC P2P
- **qrcode.react** — توليد QR Code

## 🚀 التشغيل محلياً

```bash
npm install
npm run dev
```

ثم افتح [http://localhost:3000](http://localhost:3000) في المتصفح.

## 📦 النشر على Vercel

1. ارفع المشروع على GitHub
2. اربط المستودع بحساب [Vercel](https://vercel.com)
3. سيتم بناء ونشر المشروع تلقائياً
